# Le Temple des Arcanes — V1

Cette version est une PWA (Progressive Web App) : elle peut être ouverte dans Safari et ajoutée à l'écran d'accueil de l'iPhone.

## Ce que contient cette V1
- 22 arcanes majeurs avec les personnages mythologiques validés.
- 16 figures de cour avec les choix validés.
- 40 cartes numérales structurées par nombre + enseigne + grammaire symbolique.
- Tirage de 3 cartes.
- Journal local des tirages.
- Bibliothèque symbolique.
- Interface pensée pour l'iPhone.
- Fonctionnement hors ligne après le premier chargement.

## Installation sur iPhone — méthode recommandée
1. Créer un compte GitHub sur https://github.com/ si tu n'en as pas.
2. Créer un nouveau dépôt (repository), par exemple `tarot-grec`.
3. Envoyer tous les fichiers de ce dossier dans le dépôt.
4. Dans GitHub : Settings → Pages.
5. Choisir la branche `main` et le dossier `/root`, puis enregistrer.
6. GitHub donnera une adresse du type `https://TON-COMPTE.github.io/tarot-grec/`.
7. Ouvrir cette adresse dans Safari sur l'iPhone.
8. Appuyer sur Partager → Ajouter à l'écran d'accueil → Ajouter.
9. L'application apparaîtra avec son icône et pourra être ouverte comme une app.

## Important
Cette V1 est volontairement un prototype : les visuels sont des glyphes et compositions typographiques provisoires. La prochaine étape est de remplacer chaque glyph par les illustrations mythologiques finales et d'affiner les 40 cartes numérales.
